# Pure JSON API Response Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every request to the Laravel backend return JSON, including the root route and all error responses.

**Architecture:** Replace the root `view('welcome')` route with a JSON response, and configure the exception handler in `bootstrap/app.php` to always render JSON regardless of the `Accept` header. Uses existing `App\Support\ApiResponse` helpers so all responses share the `{success, message, data}` shape.

**Tech Stack:** PHP 8.2, Laravel 12, PHPUnit (via `php artisan test`).

## Global Constraints

- All responses use `App\Support\ApiResponse::success()` / `ApiResponse::error()` helpers.
- Success shape: `{"success": true, "message": "...", "data": ...}`.
- Error shape: `{"success": false, "message": "..."}` (optional `errors` key).
- No new endpoints, no controller logic changes, no auth changes.
- Tests are PHPUnit classes in `tests/`; run with `php artisan test`.
- Docs exist at `docs/superpowers/specs/2026-08-14-json-api-design.md` — follow it exactly.

### Task 2: Error responses always render JSON

**Files:**
- Modify: `bootstrap/app.php:19-20`
- Create: `tests/Feature/JsonErrorsTest.php`

**Interfaces:**
- Consumes: `App\Support\ApiResponse::error(string $message = 'Error', int $status = 400, mixed $errors = null): JsonResponse`
- Produces: All exceptions render JSON. Notably:
  - `GET /nonexistent` → 404 `{"success": false, "message": "Not Found"}`
  - Unauthenticated API call → 401 JSON (not HTML redirect).

- [ ] **Step 1: Write the failing test**

Create `tests/Feature/JsonErrorsTest.php`:

```php
<?php

namespace Tests\Feature;

use Illuminate\Support\Facades\Route;
use Tests\TestCase;

class JsonErrorsTest extends TestCase
{
    public function test_404_returns_json_without_accept_header(): void
    {
        $response = $this->get('/this-route-does-not-exist');

        $response->assertNotFound()
            ->assertHeader('content-type', 'application/json');
    }

    public function test_unauthenticated_api_returns_json(): void
    {
        $response = $this->postJson('/api/bookings');

        $response->assertUnauthorized()
            ->assertJson(['success' => false]);
    }
}
```

Note: if the request uses `get()` without `Accept: application/json`, Laravel would normally render an HTML error page. The new configuration must force JSON in that case too.

- [ ] **Step 2: Run test to verify it fails**

Run: `php artisan test --filter=JsonErrorsTest`
Expected: FAIL — the 404 test fails because Laravel returns HTML without the `Accept: application/json` header.

- [ ] **Step 3: Configure the exception handler**

Replace the `->withExceptions(...)` block in `bootstrap/app.php` with:

```php
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\HttpKernel\Exception\NotFoundHttpException;
use App\Support\ApiResponse;

// inside ->withExceptions(function (Exceptions $exceptions): void {

$exceptions->shouldRenderJsonWhen(function (Request $request, Throwable $e) {
    return true;
});

$exceptions->render(function (NotFoundHttpException $e, Request $request) {
    return ApiResponse::error('Not Found', 404);
});
```

Exact final `bootstrap/app.php`:

```php
<?php

use App\Support\ApiResponse;
use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Exceptions;
use Illuminate\Foundation\Configuration\Middleware;
use Illuminate\Http\Request;
use Symfony\Component\HttpKernel\Exception\NotFoundHttpException;

return Application::configure(basePath: dirname(__DIR__))
    ->withRouting(
        web: __DIR__.'/../routes/web.php',
        api: __DIR__.'/../routes/api.php',
        commands: __DIR__.'/../routes/console.php',
        health: '/up',
    )
    ->withMiddleware(function (Middleware $middleware): void {
        $middleware->alias([
            'admin' => \App\Http\Middleware\AdminMiddleware::class,
        ]);
    })
    ->withExceptions(function (Exceptions $exceptions): void {
        $exceptions->shouldRenderJsonWhen(function (Request $request, Throwable $e) {
            return true;
        });

        $exceptions->render(function (NotFoundHttpException $e, Request $request) {
            return ApiResponse::error('Not Found', 404);
        });
    })->create();
```

Expected: PASS.

Run: `php artisan test`
Expected: All tests PASS (Example tests + RootJsonTest + JsonErrorsTest).
